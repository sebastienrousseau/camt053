# Getting support

Thanks for using camt053. Here's the fastest way to get help, by need.
Read the [README](README.md), the
[10-minute quickstart](docs/quickstart.md), and the runnable
[`examples/`](examples/) first; they answer most questions.

## I want to ask a question

Open a [GitHub Discussion](https://github.com/sebastienrousseau/camt053/discussions)
with your Python version, your `camt053` version
(`python -c "import camt053; print(camt053.__version__)"`), and a
minimal reproducer (CLI invocation or short snippet).

## I think I found a bug

Open a [bug report](https://github.com/sebastienrousseau/camt053/issues/new/choose)
with the same triage data plus a failing input file (redact sensitive
values) and the expected vs actual behaviour.

## I want to request a feature

Open a [feature request](https://github.com/sebastienrousseau/camt053/issues/new/choose).
Check the open [milestones](https://github.com/sebastienrousseau/camt053/milestones)
and the [ROADMAP](ROADMAP.md) first to avoid duplication.

## I need a security disclosure channel

Do not open public issues for vulnerabilities. Use
[GitHub Private Vulnerability Reporting](https://github.com/sebastienrousseau/camt053/security/advisories/new)
(preferred) or email the maintainer at
[sebastian.rousseau@gmail.com](mailto:sebastian.rousseau@gmail.com);
full policy in [SECURITY.md](SECURITY.md).

## I want commercial support

There is no paid support tier today; community support is best effort.
If your organisation needs an SLA, email the maintainer at
[sebastian.rousseau@gmail.com](mailto:sebastian.rousseau@gmail.com) so
demand can be gauged.
